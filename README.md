# Neither of Us Can Decide

Generated page listing everything currently streaming in Hungary on Netflix, Disney+,
HBO Max, Prime Video, SkyShowtime and Apple TV+, with IMDb ratings, vote counts,
Rotten Tomatoes scores, directors, cast and keywords.

`index.html` is built by the `hunow` tool and overwritten on every refresh. Do not edit
it by hand. Nothing here is written by a person, so the repository keeps a single
commit that gets amended rather than a history of 5 MB blobs.
